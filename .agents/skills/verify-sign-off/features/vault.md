## Remaining activation gates (NOT PROVEN by custody)

Ship and test these in <=300 changed-code-line PRs, keeping public vault OFF until all gates pass:

- Approved private destination/provider allowlists; bounded URL stdin; safe expiry flags; immutable Give target/filer; metadata-only board projection and event bridge. No value in answers, seen, messages, hooks, logs, errors, stdout/stderr or export. Feed removal cancels custody; terminal keys cannot resurrect.
- At-most-once Give claim/decryption/delivery with durable journal: real token file 0600, concurrent `wait --into`, destination exists/denied/symlink/traversal, expiry/refusal, crash before/after destination commit and disk/write/delete failure. Interrupted unproven delivery is `delivery-uncertain`, never re-decrypted.

- Native Receive: one-shot protected provider redirect, no server fetch/prefetch, opened is not used, independently observed owning-agent `used` versus user-reported **I finished** / `confirmed`, countdown/server expiry with tab-resume handling. No terminal reopening.
