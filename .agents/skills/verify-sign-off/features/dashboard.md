# Dashboard

Covers the cards in `web/index.html`: every item type in its area screen (see [summary.md](summary.md)), a type chip on each row, design items led by their options as tall phone frames, and the plain card for a type that has no view yet. Follow Launch and Drive in `SKILL.md` first, with a board from `init` in the scratch folder.

Build the board oldest first: `raise` a yes/no decision, `raise` a three-option decision, `raise --from` a file holding one `"type": "report"` item, `post --type design` with three options, mocks `a=mocks/a.html`, `b=mocks/b.html`, `c=mocks/c.png` (real layouts, not one heading), a long `--tradeoff` and `--recommend b`, then `post --type evidence` one update with a real screenshot as `--media`. Answer the three-option decision through `POST /api/answers`. `FIT` below is
`[...document.querySelectorAll('body *')].every(e => e.closest('.mocks') || e.getBoundingClientRect().right <= innerWidth + 0.5) && document.documentElement.scrollWidth <= innerWidth`. `SQUASH` below lists squashed text and must return `[]` at any width; it is the same check as `SQUASH` in `test/design.test.mjs`:
- **squash**: a visible element holding more than 8 characters of its own text in a column narrower than 8 characters of its font (a word squeezed to a sliver).
- **wrap**: a number or short label (6 characters or fewer, such as a tile count) on more than one line, or running out of its own box.
- **overlap**: two visible runs of text that overlap, such as a Today column's count over the caption.
`(() => { const out = [], runs = []; for (const e of document.querySelectorAll('body *')) { const nodes = [...e.childNodes].filter((n) => n.nodeType === 3 && n.textContent.trim()), t = nodes.map((n) => n.textContent).join('').trim(); if (!t || !e.checkVisibility({ visibilityProperty: true })) continue; const box = e.getBoundingClientRect(), rects = nodes.flatMap((n) => { const r = document.createRange(); r.selectNodeContents(n); return [...r.getClientRects()]; }).filter((r) => r.width && r.height); if (t.length > 8 && box.width < 8 * parseFloat(getComputedStyle(e).fontSize) * 0.5) out.push('squash:' + t.slice(0, 40)); if (t.length <= 6 && (new Set(rects.map((r) => Math.round(r.top))).size > 1 || rects.some((r) => r.left < box.left - 1 || r.right > box.right + 1))) out.push('wrap:' + t); for (const r of rects) runs.push([e, t, r]); } for (let i = 0; i < runs.length; i++) for (let j = i + 1; j < runs.length; j++) { const [ea, ta, a] = runs[i], [eb, tb, b] = runs[j]; if (ea !== eb && a.left < b.right - 1 && b.left < a.right - 1 && a.top < b.bottom - 1 && b.top < a.bottom - 1) out.push('overlap:' + ta.slice(0, 15) + '/' + tb.slice(0, 15)); } return [...new Set(out)]; })()`.
