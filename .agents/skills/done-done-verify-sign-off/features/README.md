# sign-off features

The repo's maintained verification map; a proof that drives one entry point is incomplete when this lists others.

- [Core journey](core-journey.md): the agent files a card, the person answers it in the board, the agent reads the answer, and the same journey over the previous published version upgraded in place (`done-done run core`, `done-done run upgrade`)
- [Board shell](board-shell.md): the board's areas, tokens and shell at 390 and 1280, light and dark
- [Decide](decide.md): the grouped list with swipes, More and Later, the ask with one Answer and More, the answer's check and fold, Undo, skeleton, all clear and the viewer's approve stamp, 390 light and dark, stills and a recording
- [Plan review](plan-review.md): section verdicts, Change notes, decisions and structured Send back at both widths and themes
- [Guided plan and report](guide.md): clean install and authoring, the one-scroll Guide view with read receipts and a real Go deeper, 390 and 1280, light and dark
- [Evidence media guard](evidence-text-guard.md): a text, colour-bar or placeholder still is refused at post; a real capture is posted; a colour-bar or placeholder card is not shown
- [Reports](reports.md): the list with a picture per form, read dots and the blue count, swipe right for read or unread and left to archive with Undo, More, opening reads it, on a desk the list beside the report with keys and hover actions, 390 and 1280, light and dark
- [Evidence](evidence.md): the one newest-first list with its project filter and the update screen, light and dark at 390 and 1280
- [Evidence attachment](evidence-attach.md): `post --attach` puts a downloadable file (an APK) on an update card; the file row at 390 and 1280, a real download whose bytes match, range, limits, token
- [Prototype full screen](full-screen.md): Open full screen on a design pick or an interactive page, the prototype's own navigation, Phone 390 and Desktop 1280, Reference beside or over, Close, 390 and 1280, light and dark
- [Design viewer](design-viewer.md): the full-screen screen-by-screen review, its note box and buttons at 390, 820 and 1280
- [Notification sender](notifications.md): the notify POST a local receiver gets, once per card
- [Board actions](board-actions.md): every card kind on every tab, each action clicked (Dismiss, bulk Select, answers), 390 and 1280, light and dark, with the look step
- [Today](today.md): the title with the light-or-dark button, Up next with Answer in ink, Waiting on you rows, Cleared today and Proofs today, the line into More, the More and Search sheets, 390 and 1280, light and dark, each beside the approved prototype
- [Tickets](tickets.md): `ticket` writes, lists and shows a ticket; `--ticket` on every post; the Ticket row on each card kind and the ticket's page with its cards and the tickets under it, 390 and 1280, light and dark
